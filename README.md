# Mundial Kits

Landing de camisetas oficiales del Mundial 2026, construida con **Next.js 16 + TypeScript**.

- 🌐 Producción: https://mundial-kits.vercel.app
- 📸 Instagram: [@_simonbarraza_](https://www.instagram.com/_simonbarraza_)

## Desarrollo

```bash
npm install
npm run dev
```

Deploy automático en Vercel con cada push a `main`.
